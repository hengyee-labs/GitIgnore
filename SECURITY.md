# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest `main` branch and the latest tagged release.

## Reporting a vulnerability

Please do not open a public Issue for a suspected credential leak, code execution issue or private-data exposure. Use a private GitHub Security Advisory for this repository when available. If that feature is not enabled, contact the maintainer privately through the email listed in the GitHub profile.

Include:

- affected version or commit
- macOS version and architecture
- minimal reproduction steps
- impact and any suggested mitigation

Never include real access tokens, passwords, private keys or private repository data in a report.
